# 🐱 会说话的汤姆猫 · 课堂互动版

一个**可以直接上课演示**的网页版「会说话的汤姆猫」：场景会动、能调用麦克风说话、
猫会用**变声器**把你的话重复一遍，还有三个小道具可以跟它互动。

**技术栈：只有 HTML + CSS + 原生 JavaScript + Canvas + Web Audio API。**
没有任何框架、没有任何 npm 依赖、没有任何图片/音频素材文件（音效全部现场合成）。

---

## 一、怎么跑起来（重要）

麦克风需要「安全环境」，所以**不能直接双击 index.html**，要开一个本地小服务器：

```bash
cd talking-tom
python3 -m http.server 8000
```

然后浏览器打开 **http://localhost:8000** 即可。

### macOS 一键启动
双击文件夹里的 **`启动.command`**，它会自动开服务器并打开浏览器。
（第一次如果提示"无法打开"，右键 → 打开 → 仍要打开即可。）

## 二、怎么玩

| 控件 | 位置 | 效果 |
|---|---|---|
| 🎤 麦克风 | 下方中间（最大） | 点一下开始录音 → 对着电脑说话 → 再点一下结束。**汤姆猫会用变声器把你的话重复一遍**（嘴型跟着音量动） |
| 🧹 扫把 | 下方左一 | 猫开始扫地，扫出一堆灰尘……然后**打喷嚏「阿嚏！！！」** |
| 🍰 蛋糕 | 下方左二 | 蛋糕飞过来，猫**一口一口吃掉**，掉渣渣、打饱嗝、冒爱心 |
| 🪶 痒痒挠 | 下方左三 | 挠它的痒痒，猫**哈哈大笑**，笑出眼泪和星星 |
| 🐾 摸摸头 | 下方右一 | 点它也会「喵～」（也可以直接点画面里的猫） |
| 变声滑杆 | 右上角 | 从 **-8 到 +14 半音**，越高越像卡通小奶音，越低越像大块头 |
| 退出 | 右上角 | 结束演示（会弹出"再见"页，点"再玩一次"可恢复） |

**键盘快捷键（上课很方便）**：`空格` = 说话开关　`1` 扫把　`2` 蛋糕　`3` 痒痒挠　`4` 摸摸头　`F` 全屏　`Esc` 退出

### 场景里的隐藏互动
- **鼠标移动**：整间屋子有视差，汤姆猫的眼睛会一直看着你的鼠标
- **红色皮球**：会自己在房间里弹来弹去，点一下会跳得更高，猫会盯着球看
- 墙上的挂钟走的是**真实时间**；窗外有飘动的云和飞过的小鸟；窗帘会轻轻摆动；空中有浮尘

## 三、文件结构

```
talking-tom/
├── index.html          页面结构（画布 / 顶栏 / 道具栏 / 遮罩）
├── css/style.css       全部样式（玻璃拟态道具栏、大号按钮，适合投影）
├── js/audio.js         ★ 音频引擎
│                          · 麦克风录音（MediaRecorder，带 ScriptProcessor 兜底）
│                          · 变声器：SOLA 同步叠加做时间伸缩 + 重采样做变调
│                            → 音高变了、时长不变，听起来就是"变声"
│                          · 自动裁掉首尾静音、自动增益到 0.92
│                          · 10 种音效全部用振荡器 + 噪声实时合成（喵、喷嚏、哈哈、咔嚓…）
├── js/scene.js         客厅场景绘制（墙/窗/云/钟/相框/沙发/绿植/地板/地毯/皮球）
├── js/cat.js           汤姆猫本体：全部用 Canvas 路径画出来
│                          · 眨眼 / 呼吸 / 摆尾 / 耳朵抽动 / 视线跟随
│                          · 8 种表情 + 4 种姿势 + 嘴型由音量驱动
│                          · 扫把、蛋糕、羽毛道具的绘制
└── js/main.js          主控：渲染循环、状态机、粒子系统、按钮与麦克风流程
```

## 四、上课使用小贴士

1. **先点右上角 `F` 全屏**，投影效果最好。
2. 第一次点麦克风时，浏览器会弹「允许使用麦克风」，请点**允许**。
   - 如果误点了拒绝：点地址栏左边的 🔒 图标 → 麦克风 → 允许 → 刷新页面。
3. 说话时**离麦克风 20~30 厘米**，声音清楚一点识别得更好。
   录完之后猫会安静 1.4 秒没听到声音就自动结束，所以**不要一直开着不讲话**。
4. 变声滑杆可以先设 `+6`（卡通音），讲到"低音"时拉到 `-5` 对比给学生听——
   这是讲**声音三要素（音调/响度/音色）**极好的现场演示：音调变了，但语速、时长没变。
5. 让学生轮流上来点道具和说话，参与感最强。
6. 联网不需要；断网也能用。如果是教室电脑，把整个 `talking-tom` 文件夹拷过去就行。

## 五、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 点麦克风提示"当前环境不能用麦克风" | 你是用 `file://` 直接打开的。请用 `python3 -m http.server` 起的 `http://localhost:8000` |
| 提示"麦克风权限被拒绝了" | 点地址栏 🔒 → 允许麦克风 → 刷新 |
| 提示"麦克风被其它程序占用" | 关掉腾讯会议 / 钉钉 / 录屏等正在录音的软件 |
| 猫重复的声音很怪/断续 | 这是变声器的颗粒感，把变声值调回 `0~+6` 之间最自然 |
| 页面没有声音 | 浏览器要求先有一次用户操作。点一下"开始玩"按钮即可解锁音频 |
| 投影上有黑边 | 页面用"铺满"方式缩放，属正常；按 `F` 全屏即可 |

## 六、为什么这样实现（技术说明）

* **为什么不用录音后变速播放？** 变速播放会同时改变音调和时长，声音会变快。
  这里用的是 **SOLA（Synchronous Overlap-Add）先做时间伸缩、再重采样**，
  两步叠加后 **时长不变、音高改变**，才真正像"变声器"。
* **为什么所有音效都是合成的？** 零资源文件 → 整个项目 6 个文件、不到 100 KB，
  U 盘一拷就能用，也不会因为音频解码兼容性翻车。
* **为什么用 Canvas 画猫而不是图片？** 猫的每个部位都是可编程的（嘴张开多少、
  耳朵抖一下、身体弹跳），教学演示时才"活"得起来，而且没有分辨率损失。
